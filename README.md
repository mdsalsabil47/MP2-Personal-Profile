# Personal Profile Website

A simple and responsive personal profile website developed using **HTML5 and Tailwind CSS** as part of the Mini Project 2 (MP2) for the Software Development I course at International Islamic University Chittagong (IIUC).

## About the Project

This website introduces my academic background, technical skills, projects, and contact information. It is designed with a clean layout and responsive styling for both mobile and desktop devices.

## Features

- Responsive Navigation Bar
- About Me Section
- Skills Section
- Projects Showcase
- Contact Form
- Responsive Layout for Mobile and Desktop
- Interactive Buttons and Hover Effects
- Tailwind CSS Styling

## Technologies Used

- HTML5
- Tailwind CSS
